# TeethLink Dental Hospital System — Full Enterprise Edition (النظام الكامل)

نظام المستشفى والعيادات الجامعية الكامل لطب الأسنان (كل المراحل من Phase 1 إلى Phase 5).

## المحتويات:
1. **Module 1:** المصادقة، الاعتماد، الملفات، الاستبيان الطبي الشامل، وأعلام الخطورة.
2. **Module 2:** حجز مواعيد الكشف المبدئي بنوافذ 10 دقائق مع القفل الذري `FOR UPDATE SKIP LOCKED`.
3. **Module 3:** الفرز الطبي الميداني من المشرف الأكاديمي وتوجيه الحالات للأقسام التخصصية.
4. **Module 4:** بث الحالات المباشر (InDrive-style Case Feed) وقنص الحالات ذرياً للطلبة.
5. **Module 5:** إدارة كراسي العيادات (Dental Beds & Chairs) بالمسارين: الحجز الفوري Live، والجدولة المستقبلية Calendar Tickets مع حماية الـ 30 دقيقة.
6. **Module 6:** توثيق الجلسات العلاجية، تقارير الإنجاز، معرض الحالات (Portfolio)، والتقييمات.
7. **Module 7:** المحادثات الفورية والاتصالات الصوتية بين الطالب والمريض (Real-time Chat & WebRTC).
8. **Module 8:** تقارير الإدارة والمتابعة والمهام المجدولة بالخلفية (Background Cron Jobs).

## طريقة التشغيل:
فقط اضغط نقراً مزدوجاً على:
```bat
start-full-system.bat
```
سيفتح النظام تلقائياً على الرابط:
**http://localhost:4000**
